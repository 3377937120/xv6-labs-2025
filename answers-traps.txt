1. Which registers contain arguments to functions?
   Which register holds 13 in main's call to printf?
答案：
RISC-V 调用约定使用 a0～a7 传递前 8 个整数或指针参数。
在 main 对 printf 的调用中，13 位于 a2 寄存器。

依据 call.asm：

    printf("%d %d\n", f(8)+1, 13);

对应汇编：

    24: 4635        li a2,13
    26: 45b1        li a1,12
    28: ...         生成格式字符串地址到 a0
    30: ...         jal 6f6 <printf>

参数对应关系：

    a0 = 格式字符串 "%d %d\n" 的地址
    a1 = 第一个待格式化整数，即 f(8)+1 = 12
    a2 = 第二个待格式化整数，即 13

补充：
a0 和 a1 也用于保存函数返回值；本例中 printf 的参数均属于整数或指针参数，
所以依次使用 a0、a1、a2。


2. Where is the call to f in main?
   Where is the call to g?
答案：
main 的汇编中没有真正调用 f；f 的汇编中也没有真正调用 g。
编译器把 f 和 g 内联，并进一步进行了常量折叠。

源代码关系：

    g(x) = x + 3
    f(x) = g(x)
    f(8) + 1 = 8 + 3 + 1 = 12

所以 main 中直接出现：

    26: 45b1        li a1,12

而没有：

    jal <f>

或：

    jal <g>

在 f 的汇编中同样只看到：

    14: 250d        addiw a0,a0,3

这条指令直接完成 x+3，没有调用 g。

结论：
- main 中对 f 的调用位置：不存在，已被编译器内联并常量折叠。
- f 中对 g 的调用位置：不存在，g 已被编译器内联。


3. At what address is the function printf located?
答案：
printf 位于虚拟地址 0x6f6。

依据 main 中的指令：

    30: 6c6000ef    jal 6f6 <printf>

尖括号中的 <printf> 表示目标符号，前面的 6f6 是该函数地址。


4. What value is in register ra just after the jal to printf
   in main?
答案：
ra = 0x34。

原因：
main 中调用 printf 的 jal 指令位于地址 0x30：

    30: 6c6000ef    jal 6f6 <printf>
    34: 4501        li a0,0

jal 在跳转到目标地址的同时，会把“下一条指令的地址”写入 ra。
下一条指令位于 0x34，所以调用刚发生后：

    ra = 0x34

printf 执行 ret 时，会根据 ra 返回到 main 的 0x34 处继续执行。


5. Endianness question
执行代码：

    unsigned int i = 0x00646c72;
    printf("H%x Wo%s", 57616, (char *)&i);

5.1 在当前小端 RISC-V xv6 上，输出是什么？

答案：

    HE110 World

解释：

57616 的十六进制是：

    57616 = 0xE110

当前 xv6 的十六进制数字表为：

    "0123456789ABCDEF"

所以 %x 输出 E110。

变量 i 的数值为：

    0x00646c72

在小端机器内存中的字节排列为：

    低地址 → 高地址
    0x72  0x6c  0x64  0x00
     'r'   'l'   'd'  '\0'

将 &i 强制转换为 char * 后，%s 从最低地址开始读取，得到字符串：

    "rld"

格式字符串本身提供了 "H" 和 " Wo"，因此完整输出为：

    H + E110 + " Wo" + "rld"
    = HE110 World


5.2 如果 RISC-V 是大端，为得到相同输出，i 应设为什么？

答案：

    unsigned int i = 0x726c6400;

解释：

大端机器会把最高有效字节放在最低地址。为了让内存仍按以下顺序排列：

    0x72  0x6c  0x64  0x00
     'r'   'l'   'd'  '\0'

整数值应写为：

    0x726c6400


5.3 是否需要把 57616 改成其他值？

答案：
不需要。

原因：
57616 是作为整数值传给 printf 的。%x 按数值把它转换成十六进制字符串，
而不是把它的内存字节逐字节解释成字符。处理器端序只影响多字节对象在内存中的
排列，不改变整数 57616 本身的数学值，因此仍会输出 E110。


6. What is printed after "y=" and why?
代码：

    printf("x=%d y=%d", 3);

答案：
y= 后面的值是不确定的，不能给出一个固定数字。该程序具有未定义行为。
可能打印任意整数，包含某个参数寄存器中遗留的旧值、调用者栈上的旧数据、编译器或运行环境留下的其他内容等。
